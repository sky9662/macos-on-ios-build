# Public source-only builds
- Keep proprietary game binaries, assets, credentials, signing keys, profiles, saves, device records, and private development notes outside this repository.
- Only standard GitHub-hosted runners; no paid runner labels. Preserve upstream notices and pinned dependencies.
- Never start duplicate active CI. Verify actual artifacts and release URLs. No false claims of playable game, execution, or successful JIT.
- Keep original private repository unchanged. Public releases contain diagnostics or source-only compatibility kit, never commercial content.
- Prefer existing upstream BCD/Madeira and other compatible implementations for shared functionality, pinned and credited; review license obligations before incorporating GPL app source, do not import Wine-specific dependencies needlessly.
